# نظام تطبيق حماية — النسخة الميدانية

نظام بلا خادم لحصر الطالبات في نقطة التجمع وتطبيق فرضيات الإخلاء وفق الدليل الإرشادي (سبتمبر ٢٠٢٦).
هذه الملفات برمجة فقط ولا تحتوي أي بيانات طالبات؛ البيانات تُحفظ على جوال كل مستخدمة.

## النشر على GitHub Pages (مرة واحدة)

1. ادخلي github.com واضغطي **New repository**، وسمّيه مثلاً `himaya`، واختاري **Public** ثم **Create repository**.
2. اضغطي **uploading an existing file**، واسحبي كل محتويات هذا المجلد (ومعها مجلد `vendor`)، ثم **Commit changes**.
3. من **Settings** ثم **Pages**: اختاري **Deploy from a branch**، والفرع `main` والمجلد `/ (root)`، ثم **Save**.
4. بعد دقيقة يظهر الرابط بالشكل: `https://اسم-حسابك.github.io/himaya/`

## على كل جوال

- افتحي الرابط مرة واحدة والإنترنت متاح، ثم من قائمة المتصفح اختاري **إضافة إلى الشاشة الرئيسية**.
- بعدها يعمل النظام دون إنترنت.

## التحديث

- ارفعي ملف `index.html` الجديد فوق القديم.
- غيّري رقم `CACHE` في `sw.js` (مثلاً من `himaya-v1` إلى `himaya-v2`) حتى تصل النسخة الجديدة للجوالات.

## المكتبات

- `vendor/qrcode.min.js`: qrcode-generator 1.4.4 (رخصة MIT).
- `vendor/jsqr.min.js`: jsQR 1.4.0 (رخصة Apache-2.0).

## ربط Firebase لجمع ملخصات الأثر (اختياري، مرة واحدة)

تُرسل كل مدرسة ملخص كل تمرين دون أي اسم طالبة أو معلمة، ويصلك في لوحة «دخول صاحبة المبادرة» داخل النظام مع زر تنزيل Excel.

1. ادخلي console.firebase.google.com واضغطي **Create a project**، وسمّيه `himaya` (يمكن إيقاف Google Analytics).
2. من **Build** ثم **Firestore Database** اضغطي **Create database**، واختاري أقرب موقع متاح، ثم **Production mode**.
3. من تبويب **Rules** الصقي محتوى ملف `firestore.rules`، وضعي بريدك مكان `ضعي_بريدك_هنا`، ثم **Publish**.
4. من **Build** ثم **Authentication** اضغطي **Get started**، وفعّلي **Email/Password**. ثم من **Users** اضغطي **Add user** وأدخلي بريدك نفسه وكلمة مرور.
   - يُستحسن من **Settings** ثم **User actions** إلغاء **Enable create (sign-up)** حتى لا يُنشئ غيرك حسابات.
5. من إعدادات المشروع (رمز الترس) ثم **General** ثم **Your apps** اضغطي رمز الويب `</>` وسجّلي التطبيق، وانسخي قيمتي `apiKey` و`projectId`.
6. في GitHub افتحي ملف `config.js` واضغطي رمز القلم، وضعي القيمتين مكان النص العربي، ثم **Commit changes**، وغيّري رقم `CACHE` في `sw.js` (مثلاً إلى `himaya-v2`).

بعدها: بعد أي تمرين تجدين في الإعداد زر **دخول صاحبة المبادرة**، وفيه ملخصات كل المدارس وزر التنزيل.
